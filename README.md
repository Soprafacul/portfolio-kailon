# Portfólio de José Kailon Teixeira da Silva

Projeto individual de Desenvolvimento Front-End Para Web, do curso de Análise e Desenvolvimento de Sistemas.

[Visitar o site publicado](https://soprafacul.github.io/portfolio-kailon/)

## Páginas e interação

O menu conecta a apresentação, o currículo, o formulário, a página multimídia e os gráficos. O formulário valida os campos no navegador e mostra o resultado na tela. O tema é gravado em localStorage e restaurado ao navegar ou recarregar. A página de gráficos permite variar a quantidade de pontos de um desenho em canvas.

## Evolução

O CP1 organiza as cinco páginas com HTML semântico. O CP2 adapta o layout com Flexbox, Grid e media queries. O CP3 acrescenta JavaScript, validação, persistência do tema, histórico Git e publicação em HTTPS. A versão do CP3 está na tag cp3-entrega.

No CP4, as utilidades do Bootstrap 5.3.3 organizam o menu em todas as páginas. A classe d-flex cria a linha flexível, flex-wrap permite quebrar a linha em telas estreitas, align-items-center alinha os itens e gap-1 controla o espaçamento. O link para pular a navegação leva ao conteúdo principal, que aceita foco programático. O menu indica a página atual e o botão de tema informa seu estado por aria-pressed.

O projeto contou com assistência de IA na implementação e na revisão. O vídeo individual deve demonstrar o site publicado e as escolhas do aluno.
